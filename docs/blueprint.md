# **App Name**: ScholarShip

## Core Features:

- Applicant Portal: User-friendly applicant portal for uploading transcripts, resumes, and essays.
- Dynamic Forms: Dynamic form generation with conditional questions based on applicant's GPA and other criteria.
- Admin Dashboard: Admin dashboard for managing scholarship opportunities and applicant data.
- Intelligent Matching: AI tool to match applicants to relevant scholarships based on eligibility criteria.
- Review Portal: Reviewer portal for viewing applications, leaving comments, and assigning scores.
- Notifications: Applicant status updates and notification system.

## Style Guidelines:

- Primary color: Light Blue (#ADD8E6) to convey trust and calmness.
- Background color: Very light gray (#F5F5F5) for a clean and uncluttered appearance.
- Accent color: Soft green (#90EE90) for highlighting key actions and success.
- Body and headline font: 'Inter' sans-serif for a modern and accessible look.
- Use clean, professional icons from a consistent set (e.g., FontAwesome or Material Icons).
- Employ a responsive, grid-based layout for optimal viewing on various devices.
- Subtle transitions and animations to enhance user experience and guide interactions.
